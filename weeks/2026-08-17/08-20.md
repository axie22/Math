## Core (~35 min)

### 1. Negate these, mechanically

**Rule, from §5:** walk left to right. Each quantifier flips ($\forall \leftrightarrow
\exists$). Each domain restriction ($n \in \mathbb{Z}$, $x > 0$, etc.) stays exactly as
written — only the final predicate gets negated. For $A \implies B$, the negation is
$A \wedge \lnot B$. For "and"/"or," they swap (De Morgan).

Write the correctly negated statement for each. No need to determine which one (original
or negation) is true — this is purely a mechanical exercise.

**(a)** $\forall n \in \mathbb{Z},\ n^2 \ge 0$

**(b)** $\exists x \in \mathbb{R},\ x^2 = 2$

**(c)** $\forall x \in \mathbb{R},\ \big(x > 0 \implies x^2 > 0\big)$

**(d)** A sequence $(a_n)$ is **bounded** if $\exists M > 0,\ \forall n \in
\mathbb{N},\ |a_n| \le M$. Negate this to get the definition of **unbounded**.

**(e)** $\forall x \in S,\ \big(P(x) \vee Q(x)\big)$

**(f) — requires a proof, not just a negation.** Negate $\forall x \in \mathbb{R},\ x^2
\ge x$ correctly. Then **prove the negation is true**: exhibit a specific real number
that satisfies it, and show — with the actual arithmetic, not just an assertion — that
it does.

### 2. Pigeonhole, using today's negation rule

*(This is yesterday's Core 1(b)/(c) gap, closed properly.)*

**(a)** Using §5's rule, write the negation of "$f$ is injective"
($f(a)=f(b) \implies a=b$). You should get something of the form "$\exists a, b$
with [something] and [something]."

**(b)** Prove that **no injective function $f: \{1,2,3,4,5,6\} \to \{1,2,3,4,5\}$
exists.** Structure it as a proof by contradiction: assume such an $f$ is injective,
use the definition to say something about how many *distinct* outputs it must produce,
and show that's too many for the codomain to hold.

**(c)** One sentence: state the general principle (b) is an instance of, and connect
it to why yesterday's Core 1(b) (same-size finite sets) worked out the way it did.
