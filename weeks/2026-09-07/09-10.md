## 2. Core (~30 min) — sup, one fresh instance

*Sup/inf, same material taught 09-02, zero real attempts across six exposures
and four framings so far. Today: one problem, not two, new numbers, no
worked example repeated in the file — see the note above for why.*

Recall the definition in two parts: $s=\sup A$ means (i) $s$ is an upper bound
for $A$ ($a\le s$ for all $a\in A$), and (ii) nothing smaller works — for every
$\varepsilon>0$ there is some $a\in A$ with $a>s-\varepsilon$.

**Prove:** $\sup\left\{2-\dfrac1n : n\in\mathbb{N}\right\} = 2$.

Structure: an upper-bound part, then an $\varepsilon$-part using the
Archimedean property (there exists $N\in\mathbb{N}$ with $\frac1N<\varepsilon$,
for any $\varepsilon>0$ you're handed).
