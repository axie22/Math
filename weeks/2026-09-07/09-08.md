### 2a. Worked example (from Monday, repeated here so it's in the same file as
the problems that use it)

**Claim:** $\sup\left\{1-\dfrac1n : n\in\mathbb{N}\right\} = 1$.

*Part 1 — upper bound.* For every $n\ge1$, $\frac1n>0$, so $1-\frac1n<1$. Hence
$1$ is an upper bound for the set.

*Part 2 — the $\varepsilon$-part (nothing smaller works).* Let $\varepsilon>0$ be
arbitrary. We need to find some element of the set bigger than $1-\varepsilon$.
By the Archimedean property, there exists $N\in\mathbb{N}$ with $\frac1N<\varepsilon$
(this is the same "find an $N$" move used in every $\varepsilon$–$N$ convergence
proof this month). Then the element $1-\frac1N$ of the set satisfies
$$1-\frac1N > 1-\varepsilon.$$
So no number smaller than $1$ is an upper bound — for any candidate $1-\varepsilon$,
we exhibited a set element that beats it.

Both parts done $\Rightarrow \sup\{1-\frac1n\}=1$. $\blacksquare$

**What to notice:** Part 1 is a one-line inequality. Part 2 is the part that
actually earns the word "supremum" instead of just "upper bound" — it's a direct
reuse of the $\forall\varepsilon\,\exists N$ pattern from the divergence-proof and
quantifier-order problems already retired this month.

### 2b. Your turn — a parallel instance

**Prove:** $\inf\left\{1+\dfrac1n : n\in\mathbb{N}\right\} = 1$.

This is the mirror image of the worked example (infimum instead of supremum, so
"greatest lower bound" and the $\varepsilon$-part goes the other direction: find
a set element *below* $1+\varepsilon$). Structure your answer the same way: a
lower-bound part, then an $\varepsilon$-part using the Archimedean property
exactly as above.

### 2c. Connecting sup/inf to what's already retired

**Prove:** if $A\subseteq\mathbb{R}$ is nonempty and bounded above with
$s=\sup A$, then for every $n\in\mathbb{N}$ there exists $a\in A$ with
$a>s-\frac1n$.

This is really just the $\varepsilon$-part of sup's definition with
$\varepsilon=\frac1n$ substituted in — the same specific-instance move used in
the worked example above, but now as a general claim about *any* bounded-above
set rather than one concrete sequence.
