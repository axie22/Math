## 1. Review (~10 min) — plain-English meaning, not symbol transliteration

*Retention check, first offering blank 09-04. This time, a worked scaffold comes
first — the same approach that produced the first-ever clean instance of this
skill on 09-01, reused here because a second cold blank isn't informative about
the skill either way; the goal is to actually observe the skill once more before
it goes the way of the other paused items.*

**Worked example.** Take the statement
$$\forall x\in\mathbb{R}\setminus\{0\}\ \exists y\in\mathbb{R}\ (xy=1).$$

*Symbol-by-symbol transliteration (not what this problem is asking for):* "for
every nonzero real number $x$, there exists a real number $y$ such that
$xy=1$." This is correct but it's just the symbols read aloud — it doesn't say
what the statement actually *means*.

*Plain-English meaning (what this problem is asking for):* "every nonzero real
number has a multiplicative inverse." That sentence names the mathematical fact
being asserted, in the vocabulary a reader would actually use to think about
it — it's the difference between reading a sentence in French and translating
its content into what a fluent English speaker would just say.

**Your turn — cover the worked example above and attempt this fresh instance
from memory, using only the *shape* of what "plain-English meaning" requires,
not the specific words above:**

$$\forall n\in\mathbb{Z}\ \exists m\in\mathbb{Z}\ (n+m=0).$$

Give both: (a) the symbol-by-symbol transliteration, and (b) the actual
plain-English meaning. If (a) and (b) end up being the same sentence, that's the
signal you've transliterated instead of interpreted — go back and ask what
mathematical fact the statement is naming.

## 2. Core (~40 min) — sup/inf, carried forward unchanged a second time

**Word-for-word identical to `09-07.md` and `09-08.md`.** If you've attempted

### 2a. Worked example (unchanged, kept here so the reference is always in the
same file as the problems that use it)

**Claim:** $\sup\left\{1-\dfrac1n : n\in\mathbb{N}\right\} = 1$.

*Part 1 — upper bound.* For every $n\ge1$, $\frac1n>0$, so $1-\frac1n<1$. Hence
$1$ is an upper bound for the set.

*Part 2 — the $\varepsilon$-part (nothing smaller works).* Let $\varepsilon>0$ be
arbitrary. We need to find some element of the set bigger than $1-\varepsilon$.
By the Archimedean property, there exists $N\in\mathbb{N}$ with $\frac1N<\varepsilon$
(the same "find an $N$" move used in every $\varepsilon$–$N$ convergence proof
this month). Then the element $1-\frac1N$ of the set satisfies
$$1-\frac1N > 1-\varepsilon.$$
So no number smaller than $1$ is an upper bound.

Both parts done $\Rightarrow \sup\{1-\frac1n\}=1$. $\blacksquare$

### 2b. Your turn — a parallel instance

**Prove:** $\inf\left\{1+\dfrac1n : n\in\mathbb{N}\right\} = 1$.

Mirror image of the worked example: infimum instead of supremum, so the
$\varepsilon$-part needs a set element *below* the candidate plus $\varepsilon$,
not above it. Structure: a lower-bound part, then an $\varepsilon$-part using the
Archimedean property.

### 2c. Connecting sup/inf to what's already retired

**Prove:** if $A\subseteq\mathbb{R}$ is nonempty and bounded above with
$s=\sup A$, then for every $n\in\mathbb{N}$ there exists $a\in A$ with
$a>s-\frac1n$.

This is the $\varepsilon$-part of sup's definition with $\varepsilon=\frac1n$
substituted in — a specific-instance move, now applied to *any* bounded-above
set rather than one concrete sequence.
