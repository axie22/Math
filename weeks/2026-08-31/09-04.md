## 3. Synthesis (~20 min) — uniqueness of the supremum

*Combines the oldest retired technique in Phase 0 (contradiction, §4, retired
2026-08-21) with the newest, least-tested one (the two-part $\varepsilon$
definition of sup, §9, taught 09-02, zero real attempts across two prior
offerings).*

**Prove:** if $s$ and $t$ are both suprema of a nonempty set $A\subseteq\mathbb{R}$
bounded above, then $s=t$.

This is the fact that makes it legitimate to write "**the** supremum" in the
first place — without it, the two-part definition only pins down *a* least
upper bound, not a unique one.

**Approach — proof by contradiction:** suppose $s\neq t$. WLOG $s<t$ (the setup
is symmetric in $s$ and $t$, so if instead $t<s$, swap their labels and rerun
the same argument). Since $t=\sup A$, apply the $\varepsilon$-part of *its*
definition with a specific, well-chosen $\varepsilon$ — not an arbitrary one —
and see what it forces about $s$, which you already know is an upper bound for
$A$. The contradiction is short once $\varepsilon$ is chosen correctly; most of
the work is picking $\varepsilon=t-s$ rather than leaving it generic.
