$n = 1$
LH = $2(1) = 2$
RH = $1(1 + 1) = 2$

Induction hypothesis: Assume $S(k) = 2 + 4 + 6 + ... + 2k = k(k + 1)$ for some $k \geq 1$ 

Inductive step: 
$$
\begin{aligned}
S(k + 1) &= S(k) + 2(k + 1) \\
S(k + 1) &= k(k + 1) + 2k + 2 \\

S(k + 1) &= k(k + 1) + 2(k + 1) \\
S(k + 1) &= (k + 1)(k + 2)

## R2. Contrapositive, applied — "if $5n+3$ is even, then $n$ is odd"

Contrapositive statement: If $n$ is even, then $5n + 3$ is odd.

Proof of the contrapositive: Let $n$ be an even integer. Then $n = 2k$ for some integer $k$.
$$
\begin{aligned}
&= 5(2k) + 3 \\
&= 10k + 3
&= 2(5k + 1) + 1\\
\end{aligned}
$$
$2(5k + 1)$ can be simplified to $2c$ for some integer $c$ since 2 is a factor of 10. So we get the expression $2c + 1$ which is the definition of an odd number.

Why does proving the contrapositive prove the original claim? (one sentence) A conditional statement and its contrapositive are **logically equivalent** ($P \implies Q \iff \neg Q \implies \neg P$), meaning they always share the exact same truth value.

## Repair. Plain English — $T(x,y)$: "$x-y=1$" over $\mathbb{R}$

### Part (a) Truth Values
$\forall x \exists y \, T(x,y)$ is **True**.
$\exists y \forall x \, T(x,y)$ is **False**.

### Part (b) Plain English Explanations

$\forall x \exists y \, T(x,y)$ claims:

For every real number $x$, there exists a real number $y$ such that their difference $x - y$ equals $1$ (specifically, $y = x - 1$).

$\exists y \forall x \, T(x,y)$ would have required:

A single universal constant $y$ that, when subtracted from _every_ real number $x$, always leaves $1$.

**Why no real number can do it:**

If such a fixed $y$ existed, choosing $x = 0$ would force $0 - y = 1$, meaning $y = -1$. However, testing that same $y = -1$ with $x = 5$ gives $5 - (-1) = 6 \neq 1$. Because $y$ must be fixed _before_ $x$ is chosen, no single value of $y$ can serve as the required offset for every real number simultaneously.

## Core 1 — a set of size $n$ has $2^n$ subsets

How does every subset of a size-$(n{+}1)$ set $A$ relate to subsets of
$A\setminus\{x\}$, for a chosen $x\in A$?

Base case ($n=0$): A set of size $0$ is the empty set $\emptyset$. Its only subset is $\emptyset$ itself, so it has $1$ subset. And $2^0 = 1$. ✓

Induction hypothesis (state it explicitly): Assume that any set of size $k$ has exactly $2^k$ subsets.

Inductive step: Let $A$ be a set of size $k+1$ and pick any $x \in A$. Every subset of $A$ either contains $x$ or does not:
- **Does not contain $x$:** these are exactly the subsets of $A\setminus\{x\}$, which has size $k$. By the induction hypothesis, there are $2^k$ such subsets.
- **Contains $x$:** each is a subset of $A\setminus\{x\}$ with $x$ added in, so there are also $2^k$ such subsets.

The two groups are disjoint and together account for all subsets of $A$, so the total is $2^k + 2^k = 2\cdot 2^k = 2^{k+1}$. ✓
