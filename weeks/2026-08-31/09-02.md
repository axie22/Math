## 2. Core (~35 min)

### Core 1 — strong induction, a fresh instance: binary representation

**Prove by strong induction:** every integer $n\ge1$ can be written as a sum of
distinct nonnegative powers of $2$ (i.e. $n=2^{k_1}+2^{k_2}+\cdots+2^{k_r}$ with
$k_1>k_2>\cdots>k_r\ge0$). This is exactly why every positive integer has a binary
representation.

Same mechanism as yesterday's prime-factorization problem — same reason ordinary
induction doesn't directly apply (the piece you peel off isn't always "one smaller")
— different object. Before writing the proof, answer in one line: **given $n+1$,
what's the largest power of $2$ that is $\le n+1$, and how does the leftover amount
compare to $n+1$ itself?**

- **Base case** ($n=1$): $1=2^0$.
- **Strong IH:** assume every integer $m$ with $1\le m\le n$ has such a
  representation.
- **Inductive step for $n+1$:** let $2^k$ be the largest power of $2$ with
  $2^k\le n+1$, and let $r=(n+1)-2^k$. If $r=0$, you're done immediately — say why.
  If $r>0$, argue $0<r\le n$ (so the hypothesis applies to $r$), apply the
  hypothesis to get $r$'s representation, and argue every power of $2$ in *that*
  representation is smaller than $2^k$ (so appending $2^k$ keeps all the powers
  distinct).

### Core 2 — supremum, first real proof: $\sup\left\{\dfrac{n}{n+1}:n\in\mathbb{N},\,n\ge1\right\}=1$

Read `lessons/proof-foundations.md` §9 first — new section, four short paragraphs,
one worked example ($\sup\{1-\frac1n\}=1$). This problem is structurally the same
move on a different set; don't reuse the worked example's algebra, redo it for this
set.

Two separate things to prove, both required:
1. **Upper bound:** $\frac{n}{n+1}<1$ for every $n\ge1$.
2. **Least:** for every $\varepsilon>0$, produce (in terms of $\varepsilon$) an $n$
   with $\frac{n}{n+1}>1-\varepsilon$. (Hint: $\frac{n}{n+1}=1-\frac1{n+1}$, so this
   is asking exactly the same question as the worked example, one algebraic step
   removed.)

This is the same "given $\varepsilon$, produce a witness" game as an $\varepsilon$–
$N$ convergence proof (§5) — the object you produce is different (an element of a
set, not an index), the logic is identical.

**Prove, using the two-part definition:** for nonempty sets $A,B\subseteq\mathbb{R}$
bounded above, $\sup(A+B)=\sup A+\sup B$, where $A+B:=\{a+b:a\in A,\,b\in B\}$.
