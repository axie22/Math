## R1. Bug #1 retirement check — $\sqrt5$ irrational

**Claim:** $\sqrt5$ is irrational.

Proof by contradiction. Suppose $\sqrt5$ is rational. Then write $\sqrt5 = \dfrac{p}{q}$
with $p,q\in\mathbb{Z}$, $q\neq 0$, and the fraction already in lowest terms, so
$\gcd(p,q)=1$.

Square both sides: $5 = \dfrac{p^2}{q^2}$, hence
$$p^2 = 5q^2.$$

So $5\mid p^2$. Since $5$ is prime, $5\mid p$. Write $p = 5k$ for some $k\in\mathbb{Z}$.
Then $p^2 = 25k^2$, and plugging back in:
$$25k^2 = 5q^2 \;\Longrightarrow\; q^2 = 5k^2.$$
So $5\mid q^2$, and again since $5$ is prime, $5\mid q$.

**The contradiction, spelled out:** we now have $5\mid p$ and $5\mid q$, so $5$ is a
common factor of $p$ and $q$. That directly contradicts our assumption that $p/q$ was
in lowest terms ($\gcd(p,q)=1$) — if both share a factor of $5$, the fraction wasn't
fully reduced. So no such $p,q$ can exist, which means $\sqrt5$ cannot be written as a
ratio of two integers. That is exactly what "irrational" means, so the proof is done.
$\blacksquare$

## Core 1 — $1+3+5+\cdots+(2n-1)=n^2$

**What is $S(n)$ here, and what is $S(n+1)$ in terms of $S(n)$?**

$S(n)$ is the running total $1+3+5+\cdots+(2n-1)$ — the sum of the first $n$ odd
numbers. The $n$-th *term* is $2n-1$; that's not the same as $S(n)$ (this is the
Σ-reading check). Then
$$S(n+1) = S(n) + \big(2(n+1)-1\big) = S(n) + (2n+1).$$

**Base case ($n=1$):** LHS is just the first term, $2(1)-1 = 1$. RHS is $1^2 = 1$.
$1 = 1$, so the base case holds.

**Induction hypothesis (state it explicitly):** Assume that for some fixed $n\ge1$,
$$S(n) = 1+3+5+\cdots+(2n-1) = n^2.$$

**Inductive step:** Want to show $S(n+1) = (n+1)^2$.
$$\begin{aligned}
S(n+1) &= S(n) + (2n+1) &&\text{(splitting off the last term)}\\
&= n^2 + (2n+1) &&\text{(substituting the induction hypothesis for } S(n)\text{)}\\
&= n^2 + 2n + 1 \\
&= (n+1)^2.
\end{aligned}$$
This is exactly the formula with $n+1$ in place of $n$, so whenever it holds for $n$
it holds for $n+1$. With the base case, by induction it holds for all $n\ge1$.
$\blacksquare$

The step that actually uses the hypothesis is line 2, where I replace $S(n)$ with
$n^2$ instead of re-summing $1+3+\cdots+(2n+1)$ from scratch.

## Core 2 — $3\mid(n^3-n)$ for all $n\ge1$

What does $3\mid(n^3-n)$ unfold to? (state the equation)

$3 \mid (n^3 - n)$ means there exists some $a$ such that $3a = (n^3 - n)$

Base case ($n=1$): 

(1^3 - 1) = 0
$3a = 0$ which is true if $a = 0$

Induction hypothesis (state it explicitly):

Assume $3 \mid (k^3 - k)$ holds for some arbitrary integer $k \geq 1$. That is, $k^3 - k = 3m$ for some integer $m$.

Inductive step:

We want to prove $3 \mid ((k + 1)^3 - (k + 1))$

$$
\begin{aligned}
3 &\mid ((k + 1)^3 - (k + 1)) \\
3 &\mid (k^3 + 3k^2 + 2k) \\
3 &\mid (k^3 - k) + 3k^2 + 3k \\
3 &\mid 3m + 3(k^2 + k) \\
3 &\mid 3(m + k^2 + k)
\end{aligned}
$$

$m + k^2 + k$ is just some arbitrary integer $b$ so we have $3b$ which is divisible by 3 since 3 is a factor therefore $3 \mid ((k + 1)^3 - (k + 1))$. By induction, $3 \mid (n^3 - n)$ for all $n \geq 1$.
