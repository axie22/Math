## 2. Core (~35 min)

### Core 1 — infimum, a first instance: $\inf\left\{\dfrac1n : n\in\mathbb{N},\,n\ge1\right\}=0$

Read `lessons/proof-foundations.md` §9's infimum paragraph before starting — it's
one sentence: symmetric to supremum, with $\ge$ becoming $\le$ and "$a>s-\varepsilon$"
becoming "$a<s+\varepsilon$".

Two separate things to prove, both required:
1. **Lower bound:** $\frac1n>0$ for every $n\ge1$ — so $0$ is a lower bound.
2. **Greatest:** for every $\varepsilon>0$, produce (in terms of $\varepsilon$) an
   $n$ with $\frac1n<0+\varepsilon=\varepsilon$.

This is the Archimedean property again, same as yesterday's Core 2 — the only new
content is that the two-part definition now runs in the other direction (lower
bound + nothing smaller-than-$\varepsilon$-above room works, instead of upper
bound + nothing-below-$\varepsilon$ room).

### Core 2 — a second supremum instance, different algebra: $\sup\left\{\dfrac{2n-1}{n} : n\in\mathbb{N},\,n\ge1\right\}=2$

Same two-part structure as yesterday's $n/(n+1)$ problem, but don't reuse that
algebra — redo it for this set. Hint for the rewrite: $\frac{2n-1}{n}=2-\frac1n$,
which turns both parts into the same Archimedean-property move as Core 1, just
approaching $2$ from below instead of approaching $1$ or $0$.

1. **Upper bound:** show $\frac{2n-1}{n}<2$ for every $n\ge1$.
2. **Least:** given $\varepsilon>0$, produce $n$ with $\frac{2n-1}{n}>2-\varepsilon$.
